================================================================================
PROJECT TITLE: THE VANILLA JS RECRUITER ASSESSMENT ENGINE (CONCISE SPEC)
Target Toolkit: JS Foundations (IIFE, Scope, Data Types, Loops, Callbacks, Recursion)
================================================================================
1. OBJECTIVE & SCENARIO
Build an isolated browser-based technical assessment engine (similar to HackerRank/LeetCode)
that onboards candidates, asks 5 JavaScript edge-case questions via browser dialogues (`prompt`,
`alert`, `confirm`), tracks streaks and scores in an in-memory state object, performs a recursive
audit, and outputs a formatted report via `console.table()`.

2. MANDATORY TECHNICAL REQUIREMENTS
- Scope Isolation: Wrap code in a named IIFE with `"use strict";` to prevent global scope cheating.
- Encapsulated State: Maintain `const examState = { candidateName, score, totalAnswered, currentStreak, history: [] }`.
- Higher-Order Evaluation: Write `evaluateAnswer(userAnswer, validatorCallback)` using arrow validators attached to each `questionBank` item.
- Null & Coercion Guards: Prevent crashes when `prompt()` returns `null` and guard against `Number("") === 0` false passes.
- Pure Functions & Recursion: Use pure `calculatePercentage(correct, total)` for scoring and recursive `auditCountdown(seconds)` for auditing.

3. CORE EXECUTION WORKFLOW
1. Onboard candidate via `prompt()`; safely abort with an `alert()` if cancelled (`null`).
2. Iterate through 5 questions; validate inputs, update streak/history, and `break` loop cleanly if cancelled.
3. Trigger recursive `auditCountdown(3)` and show final `alert()` scorecard graded against total questions (`questionBank.length`).
4. Prompt candidate via `confirm()` to print `console.table(examState.history)` and restart the exam.
